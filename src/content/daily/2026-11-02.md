### 今日要闻

1. **OpenAI：自 12 月起 ChatGPT 与 Codex 共用用量额度**  
自 12 月起，Plus、Pro 与 Business 计划的用量额度将在 ChatGPT 与 Codex 之间共享，背景是把 Work 的智能体能力并入主 ChatGPT 体验。用量按 token 计量；模型与任务越重，消耗一般越多；**Instant chat 不计入**该用量。帮助中心未公布各档位具体 token 数及确切切换日。  
来源：[OpenAI Help Center](https://help.openai.com/en/articles/20001625-understanding-chatgpt-and-codex-usage-limits)

2. **DeepSeek 开源 dsh-superagent 研究原型（MIT）**  
DeepSeek Harness 团队在 GitHub 公开研究原型，明确标注**非官方产品**。原型面向单个 GitHub 仓库：可监听仓库，在被授权用户提出任务时开启工作项并执行，并在原对话中回复（例如以 Pull Request 形式）。许可证为 MIT。  
来源：[GitHub 仓库 README](https://github.com/deepseek-ai/dsh-superagent-prototype/)

3. **PIF 与阿美完成 HUMAIN 股权交割：阿美持股 49%**  
阿美通过全资子公司取得 HUMAIN 49% 股权，PIF 保留 51%；阿美将在 2026 年向 HUMAIN 注入约 99 亿沙特里亚尔（约 26 亿美元）现金，并转移相关 AI、算力与数字化资产。  
来源：[Aramco 官方新闻稿](https://www.aramco.com/en/news-media/news/2026/pif-and-aramco-close-humain-transaction-to-accelerate-humains-global-growth)

4. **Apple 智能登陆中国，部分体验接入阿里巴巴千问**  
Apple 中国大陆新闻室称，首批核心 Apple 智能功能自 11 月 4 日起随最新 iOS 开发者 Beta 开放测试，并计划于 12 月随系统更新正式推出。部分体验将接入千问；**不包含**下一代 Siri AI 等 WWDC 2026 宣布功能。  
来源：[Apple 中国大陆新闻室](https://www.apple.com.cn/newsroom/2026/10/apple-intelligence-features-are-coming-to-users-in-china/) · [新华社英文报道](https://english.news.cn/20261101/773fa2ac33a34a5ca3484d7e5920d094/c.html)

5. **OpenAI 加码社区安全：可自动结束「暴力执念」对话**  
当近期对话出现对暴力或严重伤害他人的执念迹象时，ChatGPT 将能够自动结束对话；多次因此结束对话，公司可能暂时暂停账户。首份 Community Safety Report 拟于 2027 年初发布。  
来源：[OpenAI 官网](https://openai.com/index/community-safety-report-and-new-protections-for-teens)

6. **OpenAI 最新一轮融资目标下调至约 200 亿美元**  
CNBC 确认 OpenAI 正在寻求筹集至多约 200 亿美元，低于此前约 300 亿美元的目标；报道称本轮按投后估值约 1.25 万亿美元推进，融资尚未交割、数字可能变化。  
来源：[CNBC](https://www.cnbc.com/2026/10/31/openai-fundraising-20-billion-valuation.html)

7. **Anthropic 重命名 Claude 高阶套餐：Max / Ultra**  
Anthropic 将 Claude 的 Max 5x 更名为 Max、Max 20x 更名为 Ultra；价格不变，分别为每月 100 美元与 200 美元。  
来源：[The Verge](https://www.theverge.com/ai-artificial-intelligence/1023576/max-ultra-claude)
